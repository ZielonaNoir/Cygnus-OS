# PWA 图标生成指南

## 📋 图标类型说明

### UI 图标（Iconify）✅
- **用途**：界面中的图标（按钮、菜单等）
- **技术**：`@iconify/react` 库
- **状态**：✅ 已配置，正常使用
- **示例**：`<Icon icon="mdi:home" />`

### PWA 图标（静态 PNG）⚠️
- **用途**：应用图标、浏览器标签、添加到主屏幕
- **技术**：静态 PNG 图片文件
- **状态**：⚠️ 需要生成图标文件
- **位置**：`public/icons/` 目录

## 🎨 快速生成方案

### 方案一：使用在线工具（最简单）

1. **访问 PWA Asset Generator**
   - https://www.pwabuilder.com/imageGenerator

2. **准备主图标**
   - 设计一个 512×512 的图标
   - 或使用简单的文字/图形

3. **生成所有尺寸**
   - 上传 512×512 图标
   - 自动生成所有尺寸
   - 下载并放置到 `public/icons/`

### 方案二：使用 SVG 转 PNG

如果你有 SVG 图标：

```bash
# 使用 ImageMagick 或 Inkscape
# 或使用在线工具：https://cloudconvert.com/svg-to-png
```

### 方案三：创建简单占位图标

使用纯色背景 + 文字：

1. 创建 512×512 的图片
2. 背景：`#0f172a` (深色)
3. 文字/图标：`#f59e0b` (琥珀色)
4. 使用工具批量生成其他尺寸

## 📂 文件结构

生成后应放置在：
```
public/icons/
├── icon-72x72.png
├── icon-96x96.png
├── icon-128x128.png
├── icon-144x144.png
├── icon-152x152.png
├── icon-192x192.png
├── icon-384x384.png
└── icon-512x512.png
```

## 🔧 临时解决方案

当前已配置 `favicon.ico` 作为备用图标，浏览器会使用它作为临时图标。

## 📝 设计建议

- **背景**：深色（`#0f172a`）
- **图标**：琥珀色（`#f59e0b`）
- **风格**：简洁、现代、科技感
- **元素**：天鹅座抽象、几何图形、能量效果
